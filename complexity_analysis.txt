QUESTION (c) - COMPLEXITY ANALYSIS

MAX HEAP
1. Insertion:
   Worst-case time complexity = O(log n)
   Space used by heap = O(n)

2. Finding maximum:
   Maximum is stored at the root.
   Time complexity = O(1)
   Extra space = O(1)

3. Building using repeated insertion:
   Time complexity = O(n log n)
   Space complexity = O(n)

LINEAR SEARCH
1. Finding maximum:
   Time complexity = O(n)
   Extra space = O(1)

2. Appending a new score to an array with available space:
   Time complexity = O(1)
   However, finding the new maximum again by Linear Search is O(n).

FOR THE GIVEN INPUT
Number of students = 8
Maximum = 95
Max Heap construction comparisons = 12
Max Heap retrieval comparisons = 0
Linear Search comparisons = 7

The exact comparison count depends on the implementation and counting rule,
while Big-O describes how the running time grows as n increases.
